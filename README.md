# MacroDay

Ứng dụng theo dõi Calories & Macro cá nhân, React + TypeScript + Vite.

## Chạy dự án

```bash
npm install
npm run dev
```

## Bản xem giao diện hiện tại

`MacroDay-preview.html` là bản HTML độc lập mới nhất. File này chứa các điều chỉnh UI gần đây, bao gồm database thực phẩm có thể nhập tay hoặc dán dữ liệu theo thứ tự:

`Tên món | Khối lượng (g) | Protein | Carb | Mỡ | Calo`

Khi tiếp tục phát triển React, dùng `MacroDay-preview.html` làm tham chiếu giao diện và logic mới nhất.
